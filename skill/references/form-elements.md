# Form Elements

Index of S1 form components. Each maps to a documented component group in
the S1 2.0 Figma file under **Form Elements**. Detailed per-component specs
(states, variants, token usage) are a follow-up pass — this index exists so
Claude can point to the right Figma group and name the right component when
building or reviewing a form.

- Inputs
- Progress indicators
- Radio groups
- Select
- Sliders
- Toggles
- Text editors
- Tooltips
- File upload
- Checkboxes
- Button groups
- Date pickers
- Color pickers
- Calendars

## How to use this list today

Until per-component detail is filled in: when a task calls for one of the
above, reuse the named S1 component rather than building an equivalent from
scratch — check the Figma Form Elements page for the current spec, and
apply tokens from `tokens.md` (especially `border-primary`/`border-error`
for field states and the spacing scale for internal padding).
