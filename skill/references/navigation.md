# Navigation

Index of S1 navigation components. Each maps to a documented component
group in the S1 2.0 Figma file under **Navigation**. Detailed per-component
specs are a follow-up pass.

- Dropdowns
- Buttons
- Tags
- Application navigation
- Breadcrumbs
- Pagination
- Tabs
- Tree views
- Progress steps
- Slideout menus

## How to use this list today

Until per-component detail is filled in: reuse the named S1 component for
any of the above rather than building an equivalent from scratch — check
the Figma Navigation page for the current spec. Note that `border-brand`
and `fg-brand-primary_alt` tokens are the confirmed pattern for active/
selected states in components like tabs — see `tokens.md`.
