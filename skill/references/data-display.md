# Data Display

Index of S1 data-display components. Each maps to a documented component
group in the S1 2.0 Figma file under **Data Display**. Detailed
per-component specs are a follow-up pass.

- Tables
- Filters
- Avatars
- Badges
- Content dividers
- Modals
- Empty states
- Code snippets
- Activity feeds
- Alerts & notifications
- Card headers
- Charts
- Command menus
- Inline CTAs
- Video players
- Messaging
- Loading indicators
- Metrics
- Page headers
- Section footers
- Section headers

## How to use this list today

Until per-component detail is filled in: reuse the named S1 component for
any of the above rather than building an equivalent from scratch — check
the Figma Data Display page for the current spec. Success/error/warning
semantic tokens (`fg-success-secondary`, `border-error`, etc., in
`tokens.md`) are the confirmed pattern for status indicators across this
group (avatar online dots, metric deltas, alert icons).
